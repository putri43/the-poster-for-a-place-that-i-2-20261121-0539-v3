# VESPERA — The Isles That Never Touch the Sea

A travel poster for a place that does not exist. Entry for the
[make.fun bounty](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

Floating isles with waterfalls pouring into a sea of clouds, a lighthouse,
a skyferry airship, a dusk sky with moon and shooting star — rendered
procedurally by `main.ts` (Node 22, stdlib only, own PNG encoder).

## Run

```sh
node main.ts
```

Writes `/output/entry.png` and `output/entry.png` (1200×1600, deterministic).
